# Technology

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Lucide React for icons

## Architecture

- Client-side web application
- Component-based React architecture
- Responsive, mobile-first UI
- No backend required for the MVP
- Persist application data locally in the browser

## UI

Use shadcn/ui components as the foundation for the interface.
Prefer composing and styling shadcn/ui components over introducing
additional UI component libraries.

Keep the visual design clean, simple, polished, and focused on the
core routine-tracking experience.
